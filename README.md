# Брино-Авто — Android demo

Демо-приложение для СТО «Брино-Авто».

## Принципы
- Содержание и услуги основаны на информации с https://www.brino-auto.ru.
- Профиль, автомобиль и записи хранятся локально на устройстве.
- Запись в демо-версии не отправляется в сервис и не создаёт реальную заявку.
- Нет сервера, SMS-авторизации или сбора данных в облако.

## Сборка APK
GitHub Actions собирает debug APK при push в `main` и по ручному запуску.
Файл будет доступен в Artifacts соответствующего запуска workflow.

## Сборка локально
Требуются JDK 17, Android SDK и Gradle 8.9:
```bash
gradle assembleDebug
```
